# GNOSIA SOLVER (グノーシア推理ソルバー)

『グノーシア
(GNOSIA)』の推理・配役特定を強力にサポートする電脳人狼支援ツールです。\
ゲーム設定（乗員数・役職構成）および日々のイベント（CO、エンジニア調査、ドクター医療報告、**嘘の看破**、コールドスリープ、襲撃消滅など）を入力することで、成立する配役パターン（可能世界）を高速に全探索し、**神視点（客観）および各プレイヤー視点でのグノーシア確率・役職確率**をリアルタイムに算出・可視化します。

---

## 主な機能

1. **柔軟なゲーム設定**
   - 参加人数: 5人〜15人（全14名の登場キャラクター + 「自分」のプリセット対応）
   - 役職構成:
     - グノーシア (1〜6人)
     - エンジニア (1人 / なし)
     - ドクター (1人 / なし)
     - 守護天使 (1人 / なし)
     - 留守番 (2人 / なし)
     - AC主義者 (1人 / なし)
     - バグ (1人 / なし)
     - 乗員 (残り人数を自動計算)
   - プリセット: 15人フル構成、12人標準、8人シンプル

2. **イベント入力 & タイムライン**
   - **役職CO**: エンジニア、ドクター、留守番
   - **エンジニア調査報告**: 対象が「人間」か「グノーシア」か
   - **ドクター医療報告**: 冷凍された対象が「人間」か「グノーシア」か
   - **嘘に気づいた**:　直感スキル発動、プレイヤーへの密告
   - **コールドスリープ (投票)**: 冷凍された人物の記録
   - **消滅もしくは平和**: 生存者から 0〜2
     人を選択。0人（平和/犠牲者ゼロ）、1人消滅（襲撃死またはバグ調査死）、2人消滅（襲撃死＋バグ調査死）。
   - **グノーシア襲撃対象 (自分G視点)**:
     自分がグノーシアの場合に夜の襲撃先を記録。襲撃対象と異なる人物が消滅した場合はその消滅者が【バグ確定】となり、守護天使生存＆護衛成功の世界を導出。

3. **視点切り替え (Perspective Analytics) & 自分の役職保持**
   - **自分の本当の役職 (常設保持)**:
     画面上部で「自分の役職（エンジニア等）」を設定すると、全体視点や他のキャラ視点に切り替えても役職設定がリセットされず常に維持されます。
   - **全体 (客観神視点)**: 確定している客観情報のみから全員の確率を計算。
   - **プレイヤー視点**:
     - 選択した人物（例:「自分」「ラキオ」「セツ」）の視点に切り替え可能。
     - 「その人物が真エンジニアだった場合」「自分が乗員だった場合」など、役職を固定した上での残りの確率分布をシミュレーション。

4. **高速ソルバーエンジン**
   - MRV（Minimum Remaining Values）による枝刈りバックトラッキング探索。
   - グノーシア固有ルール（留守番2人ペア、バグの仕様、嘘つき除外、襲撃死の非グノーシア性）の制約伝播。
   - 矛盾・破綻の検知（「入力情報に矛盾があります」と即時警告）。
   - 「可能世界一覧」ボタンから、現在成立している具体的な配役パターンをテーブル形式で全件閲覧可能。

5. **セッションのエクスポート & インポート (保存 / 読込)**
   - ヘッダーの **「保存 / 読込」**
     ボタンから、現在のゲーム状況（設定・イベント・視点・日数）をワンクリックでJSONファイル保存（ダウンロード）またはクリップボードにコピー可能。
   - 保存したJSONファイルまたはテキストから、進行状況をいつでも完全に復元できます。

## 開発・実行方法

Deno + Vite による構成です。

### 開発サーバーの起動

```bash
deno task dev
```

ブラウザで `http://localhost:5173` にアクセスします。

### 本番ビルド

```bash
deno task build
```

成果物は `dist/` ディレクトリに出力されます。

### テスト実行

```bash
deno task test
```
